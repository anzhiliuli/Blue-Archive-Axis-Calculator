# 碧蓝档案 · 轴计算器（部署版）

在线使用：https://an.anzhiliuli.dpdns.org

- 本仓库仅存放静态构建产物（v3 / r6，构建于 2026-10-30），源码不在本仓库。
- 所有计算在浏览器本地完成，存档保存在浏览器 localStorage，不上传服务器。
- 运行时零外部请求，图标、字体、视频解封装 wasm 均随包提供。
- 数据与素材来源：SchaleDB（数据快照）、Noto Sans SC（SIL OFL 1.1）、Remix Icon（Apache 2.0）。
- 更新方式：用新构建产物覆盖 `index.html` 与 `assets/` 后提交推送。
